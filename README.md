# WCETAnalyzer (Вариант 14)

Консольное приложение на Python 3.10+ для оценки наилучшего (BCET) и наихудшего (WCET) времени выполнения фрагмента программы в процессорных тактах.

## Предметная область
**Вариант 14:** Поиск в таблице маршрутизации (сравнения и переходы). Анализируется последовательность из 8 операций, включающая извлечение IP-адресов, побитовое сравнение масок, проверку префиксов подсетей и перенаправление сетевых пакетов.

## Функционал
- Хранение моделей данных процессора и операций через `@dataclass`.
- Расчет BCET (кэш-попадания, верные предсказания переходов).
- Расчет WCET с учетом штрафов за промахи кэша и ошибки предсказания переходов.
- Вычисление коэффициента недетерминизма и раздельного вклада источников задержек (память, ветвления).
- Автоматическая проверка соблюдения заданного временного дедлайна.
- Чтение параметров вычислительной модели из внешнего JSON-файла.

## Структура проекта
- `src/` — исходный код приложения (модули main, models, services).
- `data/` — файл конфигурации процессора и фрагмента кода (`input.json`).
- `docs/` — отчетная документация по лабораторной работе.
